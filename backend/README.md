# A3Zen Backend

Enterprise AI-Driven Project & Time Management Platform.

## Features
- **Multi-Tenant SaaS Hierarchy:** Organization -> Workspace -> Project -> Sprint -> Task -> Subtask
- **View Engines:** Kanban, Calendar, High-Density Table, Gantt CPM
- **Real-Time Collaboration:** FastAPI WebSockets + Redis Pub/Sub
- **Time & Desktop Activity Engine:** Heartbeat telemetry, idle detection, presigned S3 screenshot uploads
- **Ecosystem Integrations:** GitHub 2-way Webhooks, Figma frame previews & oEmbed
- **AI Loop Engineering:** 5-Gate AI pipeline for requirements, state vectorization, TDD generation, and verification
